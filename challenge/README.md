## 范围与分类

已完成374条主清单记录的首轮网页检索，并从可访问的官方仓库、作者/参赛队仓库、博客、CTFtime和题目镜像交叉配对资料。无法保证公开网络上的全部writeup均已穷尽；首轮有搜索命中不代表命中内每个仓库都已逐题审阅。未开始、取消或延期的42条主记录暂缓。
虚拟化包含两类：QEMU/Hypervisor/虚拟机逃逸，以及自定义VM、字节码、虚拟化保护逆向；每题备注区分。Android题优先放android，车载协议/ECU/CAN题优先放车联网，嵌入式、固件、无线/硬件相关题放iot。交叉题按主方向归类，来源重复副本不重复计数。
官方source、Dockerfile和构建材料可能是上游唯一公开形式；不把它们承诺为原始比赛编译包。附件齐全指本题已登记的公开附件/源码已取得，不保证远程服务、账号、设备和外部依赖可复现。
writeup保留原文语言；部分只有官方/作者solver，已在题目说明标出。只有二进制solver或空白模板的条目不作为文字解答完成。HTML保留正文，未承诺所有外链图片都能离线显示。

下载文件进行SHA-256和长度复核；本轮登记验证2205个文件，发现0项需复查记录。ZIP另核验目录与可检查的CRC；加密包和大型展开包的限制见验证报告。没有执行任何题目二进制、exp或solver。
